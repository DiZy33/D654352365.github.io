# Открытка — техническая записка

Проект переработан: новая палитра, настоящий 3D, переписанное письмо,
исправлены баги исходной версии. Ниже — только то, что нужно знать при правке.

---

## 1. Что менять (всё в одном месте)

Открой `main.js` — первые ~90 строк, блок `CONFIG`. Больше никуда лезть не нужно:

| Поле | Что это |
|---|---|
| `password` | пароль на входе (регистр не важен, пробелы обрезаются) |
| `hint` | заблюренная подсказка под заголовком |
| `wrongAnswers` | фразы при неверном пароле (перебираются по кругу) |
| `letter` | письмо: дата, обращение, текст, подпись |
| `compliments` | что пишут лопнувшие сердечки в меню |
| `memories` | глава «Наша история»: фото + подпись + текст |
| `muse` | глава «Моя муза»: фото + текст |
| `quiz` | 3 вопроса, `correct` — индекс правильного ответа (с нуля) |
| `finale` | финальное фото, подпись под ним и признание |
| `scratchThreshold` | сколько стереть для открытия (0.68 = 68%) |

Переносы строк в текстах — обычный `\n`.

## 2. Проверка перед отправкой

- [ ] Заменил `password` на настоящий
- [ ] Прошёл весь путь от начала до финала
- [ ] Открыл с телефона (не только на ПК)
- [ ] Прогресс сбрасывается: открой ссылку с `?reset` в конце

## 3. Публикация

Залей папку целиком на любой статический хостинг (Netlify Drop, GitHub Pages,
Vercel). Открывать через `file://` тоже можно, но шрифты Google подтянутся
только при интернете, а на `file://` часть браузеров ругается на canvas.

**Важно про регистр имён файлов.** На хостинге `Final.jpg` и `final.jpg` —
разные файлы. В исходной версии из-за этого не грузилось финальное фото.
Сейчас пути совпадают с реальными именами — не переименовывай фото, не поправив
`CONFIG`.

## 4. Музыка (необязательно)

Положи файл в `assets/audio/music.mp3` — внизу справа сама появится кнопка
включения. Файла нет — кнопки нет, ничего не ломается.

## 5. Что было сделано с ассетами

- Фото ужаты до 1500 px по длинной стороне, JPEG q86 (на экране разницы нет).
- Цветы ужаты до 460 px и перекрашены цветовой матрицей под палитру проекта —
  в оригинале они были красно-жёлто-фиолетовой радугой и дрались с нежным фоном.
- **Оригиналы цветов лежат в `assets/flowers-original/`.** Хочешь вернуть —
  скопируй их поверх `assets/flowers/`.
- Итого: 5.7 МБ → ~2.8 МБ.

## 6. Исправленные баги исходной версии

1. `assets/photos/final.jpg` → реальное имя `Final.jpg` (не грузилось на хостинге).
2. Два обработчика на кнопке «Назад» — карточка закрывалась и сразу выкидывало в меню.
3. Дублирующиеся обработчики на карточках меню (остались заглушки с `console.log`).
4. `#white-flash` лежал внутри скрытого экрана — вспышка в финале не срабатывала.
5. Луг: ~500 DOM-узлов и `getBoundingClientRect()` для ~200 элементов на каждое
   движение мыши. Теперь ~108 узлов, позиции закэшированы, размытие вынесено на слой.
6. Стирание рвалось на быстрых движениях — не было интерполяции между точками.
7. Полароиды перекрывались и на ПК, и на телефоне.
8. Прогресс терялся при выходе из главы — теперь сохраняется пофотографно.
9. `scale(35)` в «нырке» давал мыло вместо вау-эффекта.
10. `@keyframes` подсказок перебивал `opacity:0` — подсказка «нажми на печать»
    висела поверх письма и не пряталась.

## 8. Мелочи, о которых легко забыть

- Приложение уважает системную настройку «уменьшить движение» — на таком
  устройстве анимации схлопываются, но всё работает.
- Гироскоп на луге: iOS спрашивает разрешение по первому тапу. Если она
  откажется — параллакс просто останется на касании, ничего не сломается.
- Текст письма и финала допечатывается по тапу — не заставляй её ждать 10 секунд.
- Если долго не может найти фото на лугу — через 14 секунд одно из них начинает
  подсвечиваться золотом.
